# 原子验收标准与测试用例

## 执行方式与共同条件

- 机制测试：`python3 tests/fullscreen/run_tests.py`。
- 真实应用与诊断：`python3 tests/fullscreen/run_tests.py --integration`。
- 指定用例：追加 `--only-testing IINAFullscreenTests/IINAFullscreenTests/方法名`。
- 原版对照：`python3 tests/fullscreen/compare_original.py e8176f27`。在 build 中提取隔离源码，生产文件来自指定提交，测试与测试工程来自当前版本；不改工作区源码。

S01–S12 位于 `run_tests.py`；D1–D5 位于 `main.swift`（编译完整生产 ViewLayer 与生产锁，播放器依赖使用替身）；H1–H7 位于 `IINAFullscreenTests.swift`（真实应用与真实 libmpv）；P1–P3 位于 `CursorCapture.swift` 的 `--self-test`。测试结束恢复临时参数域并停止、关闭测试窗口，按生产播放器池保留播放器对象，测试进程退出时结束其生命周期。

H6 是呈现诊断，不是硬件光学测量。只有实际输入≥108Hz、有效图像频率≥屏幕标称频率80%、箭头识别率≥90%、时间覆盖>1.7秒、头尾缺口<0.3秒时，才评价其光标位置变化率。捕获能力不足必须记为未验收，不得把30Hz录屏直接当作30fps硬件光标，也不得算作通过。集成运行器对跳过结果返回非零，避免误报整体验收成功。
